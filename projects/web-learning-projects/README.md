# Web Learning Projects

Ранние учебные HTML/CSS-страницы и JavaScript-игра Arkanoid Антона Никитина.

## Просмотр

Откройте `project game/arkanoid/index.html` в браузере. Остальные папки содержат версии и упражнения, а не единое приложение. Исходные названия и структура сохранены.

Некоторые HTML/CSS-страницы ожидают локальные изображения, которые не включены. Это архив практики; визуальные макеты требуют доработки перед использованием как готовые продукты.
