# Trace

Я разработал Trace — прототип рабочего места для проверки комплектности документов бизнес-клиента банка и подготовки адресного уточнения.

**Автор: Антон Никитин.**

[Открыть демо](https://osnovanie-super-bobry.bu-rchfieldadams12.chatgpt.site/)

## Мой подход

Я связываю операции с договорами и подтверждающими документами, показываю недостающие сведения и расхождения, а также основания каждого замечания. После дополнения комплекта я предусмотрел повторную проверку и подготовку проекта уточнения клиенту.
