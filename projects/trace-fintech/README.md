# Trace — Fintech Hackathon

Командный прототип для проверки комплектности документов бизнес-клиента банка и подготовки адресного уточнения. Команда: Super_Бобры.

[Демонстрация](https://osnovanie-super-bobry.bu-rchfieldadams12.chatgpt.site/)

## Материалы

- `project-brief.md`: уточнённое описание сценария, гипотез и планов пилота.
- `demo-review.md`: результаты проверки формулировок демо.

Здесь опубликовано описание командного проекта. Исходный код сайта в локальных материалах не найден; авторство всех компонентов Антону не приписывается. Метрики экономического эффекта — сценарные допущения и цели, не достигнутые результаты. Проверку ранее заявленных автоматизированных тестов доступные материалы не подтверждают.
