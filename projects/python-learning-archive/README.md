# Python Learning Archive

Архив учебных упражнений, небольших скриптов и первых Django-наработок.

Проект из учебного портфолио Антона Никитина. Исходные наработки сохранены; подготовка документации и публикации выполнена с помощью ИИ.

## Запуск

Упражнения запускаются по отдельности: `python путь/к/файлу.py`. Ноутбуки открываются в Jupyter. Зависимости отличаются между заданиями.

## Состав и ограничения

Это архив обучения, а не единое приложение. Названия учебных файлов сохранены; часть упражнений содержит незавершённые решения. Файлы других авторов не включены.

В репозиторий включён исходный код. Локальные пароли, окружения, базы, журналы и частные наборы данных исключены. Результаты и метрики не заявляются без воспроизводимой проверки.
